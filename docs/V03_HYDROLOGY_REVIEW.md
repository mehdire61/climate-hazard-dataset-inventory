# v0.3 hydrology and usability review

The development inventory contains 71 records. HUC12 is the default standardized U.S. assessment unit. A project can also use a point, an uploaded polygon or a broader WBD unit. [Open Site check](../index.html#site-check)

## Catalog decisions

| Records added | Use in a project | Scientific or access boundary |
| --- | --- | --- |
| NOAA Atlas 14 and Atlas 15 Montana Volume 1 pilot | Compare design rainfall by duration and exceedance probability. | PFDS supplies published Atlas 14 estimates and confidence limits. The accessible Atlas 15 pilot report illustrates preliminary Montana results for comparison. Its projected Volume 2 and a nationwide design product are outside this record. [Published estimates](https://hdsc.nws.noaa.gov/pfds/) · [Pilot status](https://water.noaa.gov/about/atlas15) |
| ERA5 and ERA5-Land | Compare total precipitation, runoff and snow water equivalent. | The hourly ERA5 high-resolution stream gives preceding-hour accumulations. ERA5-Land accumulations use the forecast start. SWE is a state, and neither runoff field incorporates river routing. [Compare records](../index.html#inventory?compare=era5_single_level_water_balance,era5_land_water_balance) |
| PRISM, Daymet V4 R1, gridMET and NLDAS-2 | Choose a historical precipitation forcing against the grid, accumulation interval and upstream inputs. | Daymet omits December 31 in leap years. Its integrated file search selects precipitation only. NLDAS-2 File A supplies hourly forcing. PRISM, gridMET and NLDAS can share information. [Compare forcings](../index.html#inventory?compare=prism_conus_daily_ppt,daymet_v4r1_daily_prcp,gridmet_daily_precipitation,nldas2_hourly_forcing_precip) |
| U.S. Drought Monitor and USGS discrete groundwater levels | Compare regional drought classification with well-specific observations. | D0–D4 are ordered classes. Well parameter 72019 is depth below local land surface. Retain well, aquifer, reference and observation qualifiers. [USDM permission](https://droughtmonitor.unl.edu/About/Permission.aspx) · [USGS field measurements](https://api.waterdata.usgs.gov/ogcapi/v0/collections/field-measurements?f=html) |
| SMAP enhanced L3 and L4 | Inspect surface wetness or root-zone soil moisture. | L3 retrieves shallow soil moisture on 9 km postings. L4 assimilates brightness temperatures into a land model and provides a root-zone estimate. The two share sensor information. [Compare SMAP records](../index.html#inventory?compare=smap_l3_enhanced_surface_moisture,smap_l4_surface_rootzone_moisture) |
| OpenET and MODIS MOD16A2GF | Estimate actual ET at field or basin scale. | The selected OpenET v2.0 asset documents monthly ensemble depths through 2024. MOD16A2GF supplies scaled composite totals, with a shorter final period each year. [Compare ET records](../index.html#inventory?compare=openet_ensemble_monthly_v2,modis_mod16a2gf_actual_et,gleam_v4_2a_actual_evaporation) |

Five additions support in-app NASA file discovery. For a Maryland point on April 1, 2024, the normal application route found a Daymet annual precipitation grid, 24 NLDAS hourly files, and candidate file links for both SMAP products and MOD16. These checks establish the returned metadata. Observation values, valid pixels and spatial representativeness require inspection of the scientific files. Public samples also cover a NOAA frequency table, a USGS groundwater reading and a weekly USDM archive. [Dated provider checks](evidence/hydrology/catalog-review.json)

## Findings resolved

| Workflow | Change and verification |
| --- | --- |
| Hydrologic units | Search accepts a missing state label while validating code, name and selected polygon. Live checks loaded Aguijan Island HUC12, the Potomac HUC6 and HUC4, and Mid-Atlantic HUC2. Full-detail validation still rejects invalid polygons. Regional screening records its angular tolerance and any union used to dissolve touching rings. Saved projects preserve the accepted geometry and its hash. StreamStats and NLDI provide separate outlet-based routes. |
| MRMS and partial coverage | The selected domain drives the request prefix for radar QPE, both multisensor passes and MESH. Where domains overlap, the user selects one. Archive evidence covers all 20 domain/field pairs. Original project dates and geometry are carried forward with a partial-fit warning. [NOAA prefix checks](evidence/access/mrms-regional-prefixes.json) |
| Compare | Open-ended publication policies have a separate timeline style. When a common period cannot be established, the comparison explains why. A comparison link contains the ordered dataset IDs and shows its copy result inside the comparison panel. |
| Starting datasets | Shortlists account for monitored lake locations, the selected GFED4 archive endpoint, offshore sites and local snow products. SWE and forcing products are available as antecedent flood inputs. Regression cases cover direct gauges in the U.S. and Kenya, local radar, mountain snow and an offshore project. |
| Station access and exports | All 897 bundled SNOTEL directory entries carry provider elevation and operating dates. Multi-year requests offer annual links and an optional batch script. USGS daily mean discharge displays a daily time step. Site CSV rows include vertical reference, terms ID and commercial-use and redistribution statuses. MRMS sibling records use the shared NOAA distribution terms. |
| Technical discovery | Search covers formats, IDs, units and vertical references, including both spellings of NAVD 88. Time sorting uses the earliest structured start and places unknown starts last in both directions. Record dialogs show the canonical terms ID used in CSV. |
| Working in Site check | Opening a record from Inventory reveals and focuses its detail panel. CMR and STAC file results survive dataset changes for the submitted project. Changed project inputs require a new search. CO-OPS product and datum controls appear beside the observation preview. Changing either clears the earlier preview before another retrieval. |
| Mobile and offline reports | Small action buttons have a 44 px mobile target. A screening brief with no starting datasets names the empty result. Browser checks exercise the existing saved observations, raw data exports, gap plots, maps and offline entry points. |
